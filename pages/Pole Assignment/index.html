Interactive discrete-time control design based on the 2nd-order Servomotor model.

The Theory

In this system, we use full-state feedback to control the motor's position and velocity. The control law is \( u(k) = -Kx(k) \). By carefully calculating the gain matrix \( K = [K_1, K_2] \), we can place the closed-loop poles (the roots of the characteristic equation) exactly where we want them in the Z-plane.

Stability Rule: In discrete-time systems, the system is stable if and only if all poles reside strictly inside the unit circle (radius < 1). If they exit the circle, the system becomes unstable and blows up.

Key Concepts
Ackermann's Formula K = eₙᵀ · C⁻¹ · φ(A), where φ is the desired characteristic polynomial.
Requirement Pole placement requires the system to be fully controllable.
Trade-off Placing poles farther left → faster response but larger control effort.
